# Vienounce Core: Basic Model Benchmarks

This document outlines the benchmark metrics and expected performance for the open-source, offline **Vienounce Core** library. 

Vienounce Core uses a hybrid Whisper-Base ASR + pre-trained Wav2Vec2 espeak-ng forced alignment pipeline on CPU/GPU. It serves as the baseline diagnostic engine before applying custom phonetic adapter fine-tuning or RLHF calibration.

---

## 📊 Gold Standard L2-ARCTIC Validation

The basic version was benchmarked on the gold-standard **L2-ARCTIC corpus** (`vuihocrnd/l2-arctic-cleaned`), focusing on speech recordings from native Vietnamese English-learners (`TLV`, `TXHC`, `THV`, `HQTV`, `PNV`). 

Acoustic scores generated by the forced-alignment pipeline were evaluated against gold phonetics compiled by expert phoneticians.

### 1. Acoustic Score Distributions

These values represent the raw posterior log-probability GOP score means for phonemes pronounced correctly vs. those with L1 transfer errors or drops:

| Category | Mean GOP Score | Standard Deviation (Std) |
| :--- | :--- | :--- |
| **Correct Pronunciations** | `-1.10` | `1.45` |
| **Incorrect / Dropped Phonemes** | `-1.95` | `1.97` |
| **Overall Score Separation** | **`0.85`** | — |

For critical L1-transfer phonemes (such as final plosive codas `/k, t, p/` and final sibilants `/z, s/`):
- **Correct Target Phonemes (Mean GOP)**: `-0.75`
- **Incorrect / Dropped Target Phonemes (Mean GOP)**: `-1.82`

## 🎯 Diagnostic Alert Accuracy

Coaching alert thresholds are calibrated using standard grid search optimization to detect pronunciation errors (accented/dropped phonemes) at a standardized alert threshold of `-2.5`:

| Metric | Basic Version Performance |
| :--- | :--- |
| **Precision** | **`50.6%`** |
| **Recall** | **`28.9%`** |
| **F1-Score** | **`36.8%`** |
| **Latency (CPU)** | **`1.1 seconds`** (average per sentence) |

### What this means for the user:
- **Precision (50.6%)**: Out of all phonetic alerts flagged by the system, approximately 50.6% represent true pronunciation drops or distinct accent errors.
- **Recall (28.9%)**: The system successfully catches and highlights 28.9% of all pronunciation errors made by Vietnamese learners.
- **Latency**: Sub-second execution on standard commodity CPUs makes it highly responsive for offline practice.

## 🔬 How to Run the Benchmark Script Locally

You can evaluate the basic offline model pipeline locally by running the validation suite:

```bash
# Navigate to the core directory
cd vienounce-core

# Execute validation against 100 gold-standard L2-ARCTIC samples
uv run python validate_l2arctic.py
```
This script downloads clean audio clips and metadata, aligns the espeak IPA sequences using the default alignment service, and prints the overall precision, recall, and accuracy metrics for the basic model.
